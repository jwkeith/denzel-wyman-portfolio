# Bilingual Customer Care & Technical Support Portfolio

Welcome to my personal portfolio website repository! This site showcases my professional experience, technical skills, and background in enterprise cloud support, FinTech customer care, and billing operations.

 live Demo: [https://jwkeith.github.io/denzel-wyman-portfolio/](https://jwkeith.github.io/denzel-wyman-portfolio/)

---

##  Overview & Features

- **Responsive Design:** Optimized for seamless viewing on desktop, tablet, and mobile devices.
- **Interactive Contact Form:** Integrated with **EmailJS** for direct client and recruiter communication.
- **Modern UI/UX:** Styled with custom CSS variables, dark-mode styling, and smooth-scroll navigation.

---

##  Core Competencies Highlighted

- **Cloud & Technical Support:** Exchange Online, Mail Flow Diagnostics, NDR Error Analysis, Calendar Routing, Ticket Escalations.
- **FinTech & Customer Care:** Bilingual Support (English/Spanish), Fraud Disputes, Financial Guidance, Customer Retention.
- **Operations & Billing:** Medical Insurance Verification, Payment & Billing Operations.
